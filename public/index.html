连接模型与使用说明

在项目的 .env 中填写模型地址、名称和 API Key，然后重启本地服务。密钥保存在本机，不传给插件页面。

使用云端模型时，选定的文字与修改要求会发送至该供应商。使用本地模型时，推理在本机进行；Office.js 仍由微软 CDN 加载。

支持普通正文段落，保留未修改文字的格式。暂不处理已有修订、批注、域、链接、图片和段内手动换行。
